# Синхронизация проекта между компьютерами

На основном компьютере запустите:

```text
<LOCAL_PATH>
```

Источник: `<LOCAL_PATH>`. Копия: `<LOCAL_PATH>`.
Синхронизируется **весь def_AI**, включая соседние проекты, скрытые файлы, `.git`, `.env`, модели, видео и виртуальные окружения. Файлы вне этого каталога не затрагиваются. Оригинал сохраняется.

После успешного завершения подключите внешний диск к ноутбуку и запустите **с внешнего диска** файл `Git\AI_PIC_DEF\def_AI\img-style-ag_1\sync_H_to_C.bat`. Буква диска может быть любой: скрипт определяет её по собственному расположению. Например, если Windows назначила букву F:

```text
<LOCAL_PATH>
```

Источник в этом примере: `<LOCAL_PATH>`. Копия: `<LOCAL_PATH>`. Имя `sync_H_to_C.bat` сохранено для совместимости; буква H в имени не задаёт источник. Не переносите BAT или PS1 отдельно на рабочий стол: запускайте BAT прямо из папки проекта на внешнем диске. Запуск ноутбучного режима с C блокируется.
Отсутствующий каталог на C создаётся автоматически. Если проект на ноутбуке нужен в другом каталоге, сначала измените конфигурацию скрипта; текущий вариант использует именно этот путь.

## Что происходит при запуске

1. Проверяются пути, наличие дисков и маркера проекта в источнике. Ссылки/junction в деревьях или их родителях приводят к остановке с указанием пути: скрипт не должен переходить в посторонние каталоги.
2. Выполняется предварительный просмотр Robocopy: файлы проекта не меняются. `*EXTRA` обозначает лишние объекты копии, которые будут удалены. Итоговая таблица показывает объём работы.
3. Для применения введите `MIRROR` и нажмите Enter. Просто Enter отменяет операцию.
4. Сначала копируются новые и изменённые файлы. Если копирование завершилось без ошибок, отдельный проход удаляет лишнее в копии. Удаление окончательное, без корзины. Более новые файлы копии также заменяются версией источника.
5. Повторный предварительный просмотр проверяет отсутствие оставшихся различий. При ошибке исправьте причину и повторите запуск: уже совпадающие файлы пропускаются.

До запуска закройте программы и процессы, меняющие любой из этих каталогов. Не редактируйте файлы во время синхронизации. Операция не является атомарной: при прерывании копия может быть частично обновлена.

Без запроса на применение, только просмотр:

```bat
sync_E_to_H.bat -PreviewOnly
```

Журналы каждого прохода сохраняются вне проекта: `%LOCALAPPDATA%\DefAI-Mirror-Logs`.

## Границы сравнения и переносимость

Robocopy сравнивает размер, время изменения и атрибуты; содержимое совпадающих по размеру и времени файлов не хешируется. Неизменённые файлы не переписываются. ACL, владельцы и аудит Windows не зеркалируются; это копия дерева файлов, а не клон диска. Для максимально точного сохранения файловой информации предпочтителен NTFS.

Копирование не переписывает абсолютные пути внутри конфигураций и проектов Premiere. Виртуальное окружение Python после смены компьютера/диска может потребовать пересоздания; само по себе наличие копии не означает готовность всех программ к запуску.

В исходном запросе также упоминался диск I. По умолчанию выбран E. Если оригинал действительно на I, используйте явно:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\mirror_def_ai.ps1 -Direction I-to-H
```

Не запускайте H → C до успешного окончания E → H.
