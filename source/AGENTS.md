# Инструкции для агентов проекта

Для задач генерации видео, озвучки, монтажа `.prproj`, цветокоррекции и анимации прочитай `.cursor/skills/premiere-offline-first/SKILL.md` и применяй его вместе с подходящей инструкцией конкретного workflow. Для несвязанных задач этот skill не нужен.

Предпочтение пользователя: максимум работы выполнять Python/API/FFmpeg без открытого Premiere; Adobe использовать только для действительно необходимых нативных операций и обязательных проверок. Сохраняй редактируемость эффектов. Не подменяй нативный QA предпросмотром FFmpeg и не отменяй явно требуемый open-check.

Каноническая версия skill хранится в этом репозитории, в `.cursor/skills/premiere-offline-first/SKILL.md`. Личная копия Codex может быть установлена в `$CODEX_HOME/skills/premiere-offline-first/` (по умолчанию `~/.codex/skills/premiere-offline-first/`). В этом проекте используй актуальную репозиторную версию.
